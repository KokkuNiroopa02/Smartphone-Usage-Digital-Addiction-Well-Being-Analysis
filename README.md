📱 Smartphone Usage Analysis Dashboard
📌 Project Overview

This project focuses on analyzing smartphone usage data using SQL Server and Power BI. The main aim is to understand smartphone usage patterns and present the results through an interactive dashboard.

🔄 Project Flow

Data Collection → Data Cleaning → SQL Server Connection → Power BI Connection → Data Analysis → Dashboard

📊 1. Data Collection

The smartphone usage dataset is collected from a suitable data source. The dataset contains information about users, screen time, gaming hours, sleep hours, app usage, notifications, and other smartphone-related activities.

🧹 2. Data Cleaning

The collected data is checked and prepared before analysis.

The following steps are performed:

Checking for missing values.

Removing duplicate records.

Correcting data errors.

Organizing the data into a proper format.
This helps to improve the accuracy of the analysis.

🗄️ 3. SQL Server Connection

The cleaned dataset is stored in SQL Server for easy data management.

The following steps are performed:

A database is created in SQL Server.

A table is created to store smartphone usage data.

The cleaned data is inserted into the table.

SQL queries are used to check and retrieve the data.

SQL Server acts as the database for this project.

🔗 4. Power BI Connection

Power BI is connected to SQL Server to retrieve the stored data.

The connection process includes:

Open Power BI Desktop.
Select Get Data.
Choose SQL Server.
Enter the server and database details.
Select the required table.
Load the data into Power BI.

Power BI is used to analyze the data and create interactive visualizations.

📈 5. Data Analysis and Visualization

After connecting the data to Power BI, different charts and graphs are created to understand smartphone usage patterns.

The analysis focuses on:

Daily screen time.
Weekend screen time.
Gaming hours.
Sleep hours.
App usage.
Notifications.
User activity patterns.
Smartphone addiction-related patterns.

📊 6. Power BI Dashboard

An interactive dashboard is created using Power BI.

The dashboard helps users understand smartphone usage patterns through charts, graphs, cards, and filters.

Users can interact with the dashboard to explore different aspects of the data.

🎯 Project Objectives
To analyze smartphone usage patterns.
To understand users' daily smartphone activities.
To store and manage data using SQL Server.
To connect SQL Server with Power BI.
To create an interactive dashboard.
To present meaningful insights from the data.

🛠️ Tools and Technologies
Database: Microsoft SQL Server
Data Visualization: Microsoft Power BI
Data Preparation: Power Query
Programming Language: SQL
Platform: GitHub

🔍 Conclusion

This project collects and cleans smartphone usage data, stores it in SQL Server, and connects it to Power BI for analysis.

The final dashboard presents the data in a simple and interactive way, helping users understand smartphone usage patterns and discover useful insights.
